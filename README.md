## 主要功能

- 今日屏幕使用统计：显示今日已用时间、剩余时间和常用应用分钟数。
- 应用白名单：重要应用可放行，普通时间限制不会误伤；护眼休息仍会生效。
- 应用限额：可以为单个应用设置每日可用时长。
- 全局规则：设置每日总时长、连续使用提醒、20-20-20 护眼休息。
- 权限体检：检查使用情况访问、无障碍服务、悬浮窗、通知和电池优化状态。
- 使用日志：在本地记录锁定、提醒、异常操作和配置变化，方便自己复盘。
- 休息提醒：到达休息条件后显示倒计时和提示语，结束后自动继续。
- 跨设备护眼计时：使用电脑、平板时手动开始，每 20 分钟响铃提醒远眺，20 秒休息结束后再次响铃并进入下一轮；支持暂停、继续、结束和铃声试听。
- 新版页面：统一导航、安全边距和按钮尺寸，优化白名单、应用限额、规则、权限、日志与检测页。

## 安装说明

1. 下载 APK 到 Android 手机。
2. 允许安装来自浏览器或文件管理器的应用。
3. 打开“家庭健康”，按权限体检页提示授予必要权限。
4. 根据自己的需要配置白名单、应用限额和全局规则。
5. 使用跨设备计时时，另需允许“闹钟和提醒”及计时通知，并确认系统闹钟音量可听见。

跨设备计时不会主动关闭屏幕或要求重新解锁，也不会替你更改系统自动息屏设置。铃声使用闹钟音量；静音、勿扰、通话和厂商后台策略可能影响提醒。重启后计时会暂停，需要手动继续。强行停止应用后无法保证提醒送达。
